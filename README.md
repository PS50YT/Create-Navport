# ⚙️ What is Create mod?

<iframe width="560" height="315" src="https://www.youtube-nocookie.com/embed/rR8W-f9YhYA" title="YouTube video player" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" allowfullscreen></iframe>

The Create Mod is a popular mechanical engineering modification for Minecraft that replaces traditional, menu-heavy automation with physical, animated machinery. Instead of abstract energy systems, it operates entirely on rotational power (measured in speed and stress) generated by windmills, water wheels, or steam engines. Players physically route this power using gears, belts, and shafts to build open-air factories, where items are visibly processed, sorted, and transported in real-time right before your eyes.
Its key features include interactive components like mechanical presses, mixers, conveyor belts, and a highly customizable train system for moving goods. Using these tools, you can build fully automated resource farms, automatic ore processors, massive transit networks, and moving architectural structures like working drawbridges, elevators, or secret doors.
